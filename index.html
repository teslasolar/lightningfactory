03 Experimental Protocols

3.1 Study 1: Acute Cognitive Effects (Lab)

Design: Randomized Double-Blind Crossover — N=60 healthy adults

(Power analysis: d=0.5, α=0.05, β=0.80)

Screening → Baseline → Condition A → Washout (7d) → Condition B ┌────────┐ ┌─────────┐ ┌──────────┐ ┌───────┐ ┌──────────┐ │Health │ │Cognitive│ │ 60 min │ │ │ │ 60 min │ │screen │ │battery │ │ exposure │ │ │ │ exposure │ │EEG cap │ │EEG rest │ │ + tests │ │ │ │ + tests │ └────────┘ └─────────┘ └──────────┘ └───────┘ └──────────┘ Conditions: ACTIVE (7.83 Hz + harmonics, 1-10 µT) vs SHAM (device on, 0 field) Randomization: Counterbalanced — half get Active first, half Sham first Blinding: Participants & testers unaware of condition

Primary Outcomes (Cognitive Battery)

Working memory — N-back task (2-back, 3-back): accuracy %, reaction time
Attention — Continuous Performance Test: d' sensitivity, commission errors
Executive function — Trail Making Test (A & B): completion time, errors
Processing speed — Symbol Digit Modalities Test: correct responses in 90s
Creativity — Alternate Uses Task: fluency, flexibility, originality

Secondary Outcomes (Physiological)

EEG — Power spectral density, coherence with applied field, alpha peak frequency shift
Heart Rate Variability — RMSSD, SDNN, LF/HF ratio
Salivary cortisol — Pre/post exposure samples
Subjective — VAS (alertness, focus, mood), NASA Task Load Index

Statistical Analysis Plan

Mixed-effects model:
  Y = β₀ + β₁(Condition) + β₂(Order) + β₃(Period) + uᵢ + ε

Multiple comparison correction: Benjamini-Hochberg FDR (q < 0.05)
Effect size: Cohen's d with 95% CI
Responder analysis: Subgroups by baseline alpha power
EEG-behavior correlation: Does Δalpha predict Δcognition?

3.2 Study 2: Chronic Workplace Effects (Field)

Design: Cluster-Randomized Controlled Trial — 8 offices, 12 weeks

Site selection: 8 comparable open-plan offices (same company) Randomization: 4 offices → Active | 4 offices → Sham Duration: 12 weeks | Operation: 8am-6pm weekdays Blinding: Participants — Told "environmental optimization system" Managers — Unaware of condition assignment Data collectors — Blinded to office condition

Primary Outcomes

Objective work output — Lines of code / commits, documents completed, tickets closed
Error rates — Quality metrics from existing systems
Meeting efficiency — Decisions per meeting-hour (observer-rated)

Secondary Outcomes

Cognitive tests — N-back, Symbol Digit (monthly, 5-min battery)
Wellbeing surveys — WHO-5, PSS-4, Pittsburgh Sleep Quality (weekly)
Physiological — Wearable HRV continuous, morning salivary cortisol (n=40)
Sick days taken & Employee turnover intent

Power Analysis

Minimum detectable effect: 8% productivity increase
ICC (intra-cluster correlation): 0.05
Average cluster size: 25 employees
Design effect: 1 + (25-1)(0.05) = 2.2
Effective sample size per arm: 100 / 2.2 ≈ 45
Clusters needed per arm: 45 / 25 ≈ 2 (with buffer: 4)
Total: 8 offices, ~200 participants

PIVOT if: Physiological effects (EEG, HRV) but no cognition → reframe as wellness/stress-reduction device
TERMINATE if: No significant effects, effects identical between 7.83 Hz and mismatch, sham performs equal or better

PROCEED if: Productivity increase ≥5%, OR wellbeing improvement ≥0.5 SD, positive ROI for customers, no adverse effects pattern

Appendix B: Firmware Pseudocode

// LIGHTNING_FACTORY_v1.0
// Schumann resonance generator firmware

#define F1  7.83   // Fundamental
#define F2  14.30  // 2nd harmonic
#define F3  20.80  // 3rd harmonic
#define F4  27.30  // 4th harmonic
#define F5  33.80  // 5th harmonic
#define F6  39.00  // 6th harmonic

float amplitudes[] = {1.0, 0.6, 0.4, 0.25, 0.15, 0.10};
float phases[]     = {0, 30, 60, 90, 120, 150};

void setup() {
    init_dds();
    init_amplifier();
    init_magnetometer();
    init_wifi();
    init_logging();
    set_field_strength(10.0);  // µT
    set_frequencies({F1, F2, F3, F4, F5, F6});
    set_amplitudes(amplitudes);
    set_phases(phases);
}

void loop() {
    update_dds_output();
    float measured_field = read_magnetometer();

    // Closed-loop control
    if (abs(measured_field - target_field) > 0.1) {
        adjust_amplifier_gain();
    }

    // Log data every second
    if (millis() - last_log > 1000) {
        log_to_sd(timestamp, measured_field, target_field);
        upload_to_cloud();
        last_log = millis();
    }

    if (wifi_command_available()) {
        process_command();
    }
}
